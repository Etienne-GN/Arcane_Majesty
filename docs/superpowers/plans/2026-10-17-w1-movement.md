# W1 Movement (Sprint, Hop, Vigor) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the player a sprint (Shift) and a hop (Space) that clears low obstacles and doubles as a dodge, paid for with a new Vigor resource, on keyboard, touch and gamepad.

**Architecture:** All numbers and decisions live in a pure module `src/systems/movementRules.js` (Vigor ticking, hop landing search, which decorations are hoppable). `Player` consumes it for sprint speed, the hop motion and hop i-frames; `GameScene` owns input, a new `hopGroup` of static bodies the hop ignores, and the collision query the landing search needs. Blink-Step moves from Space to H.

**Tech Stack:** Phaser 3.90 (Arcade physics), plain ES modules, Node `assert` tests chained in `npm test`, headless checks via `../tool_suite/lpc_forge/tools/console.mjs`.

**Spec:** `docs/superpowers/specs/2026-10-17-world-scale-design.md` (section W1)

## Global Constraints

- Every new save field gets a default in `PlayerStats` (constructor and `reset()`), and old saves load without errors.
- Every pure module gets a `tools/test_*.mjs` test chained into `npm test`.
- Every system is checked headless in the running game via `tools/console.mjs` and `window.__game` before it is called done.
- Existing maps keep working unchanged at every step; `npm test` stays green.
- The manual (`docs/manual/index.html`) is regenerated when items, controls or systems change.
- Commits go straight to `main`.
- Work from `apps/amo` (all paths below are relative to it unless they start with `docs/`, which is the repo root).

## Rulings against the spec (made while planning)

- **"Stamina" is named Vigor.** `PlayerStats.attributes.stamina` already exists (an attribute shown on the stats screen). Two different "Stamina"s would confuse players and code. The resource is `stats.vigor` / `stats.maxVigor`, HUD label `VG`. Formula and numbers are the spec's.
- **Vigor is not saved.** It refills in seconds; a reload starts full. No save field, so no save default is needed; `SaveManager.load` sets it to full.
- **Blink-Step goes to H, not the hotbar.** The hotbar (`systems/hotbar.js`) holds consumable items only; Blink-Step is a skill with its own key path (`_tryBlink`), as Aetheric Sight is on V. H is free. Touch keeps its BLK button.
- **Hop cells (`hopCells`) apply to placed decorations only in W1.** A map can list `hopCells: [[x, y], ...]`; a decoration whose body sits in one is hoppable (narrow streams drawn as water decorations). The tile-grid `hop` layer arrives with W2's region format.

## Review Focus

1. Hop started while touching a wall or fence (body already overlapping) — must still pick a sane landing, never land inside the wall. Pinned in Task 1's tests (start cell is a hop cell).
2. Damage during a hop after the 0.25 s window — must hurt normally (i-frames end on time). Pinned in Task 3's headless check.
3. Pressing Space while winded with < 25 Vigor — must refuse with a message, not hop. Pinned in Task 1 (`spendHop`) and Task 3's headless check.
4. Old saves loading after this change — Vigor full, no crash, Blink-Step level kept. Pinned in Task 2's test.
5. Sprint while slowed by a status — the multipliers stack (slow × 1.6), never reset the slow. Pinned in Task 1 (`moveSpeed`).

```js
// Movement rules (W1): Vigor, sprint speed, hop landing, hoppable decorations.
// Pure — tools/test_movement.mjs. Player and GameScene consume it.

export const MOVE = {
    SPRINT_MULT: 1.6,
    SPRINT_DRAIN_PER_S: 20,
    VIGOR_REGEN_PER_S: 25,
    VIGOR_REGEN_DELAY_MS: 800,
    WINDED_RESUME: 30,      // a winded player sprints again once Vigor is back to this
    HOP_COST: 25,
    HOP_MS: 450,
    HOP_IFRAME_MS: 250,     // the dodge: invulnerable for the start of the hop
    HOP_MAX_DIST: 64,       // two tiles
    HOP_LIFT: 10,           // px the sprite rises at the top of the arc
};

export const vigorMax = agility => 100 + 2 * Math.max(0, (agility ?? 0) - 10);

// s: { vigor, maxVigor, vigorWinded, _vigorIdleMs }. Sprinting only spends when allowed;
// holding Shift while winded is just walking, and Vigor keeps recovering.
export function tickVigor(s, dtMs, sprinting) {
    const spending = sprinting && canSprint(s);
    if (spending) {
        s.vigor = Math.max(0, s.vigor - MOVE.SPRINT_DRAIN_PER_S * dtMs / 1000);
        s._vigorIdleMs = 0;
        if (s.vigor <= 0) s.vigorWinded = true;
        return;
    }
    s._vigorIdleMs = (s._vigorIdleMs ?? 0) + dtMs;
    const regenMs = Math.min(dtMs, s._vigorIdleMs - MOVE.VIGOR_REGEN_DELAY_MS);
    if (regenMs > 0) s.vigor = Math.min(s.maxVigor, s.vigor + MOVE.VIGOR_REGEN_PER_S * regenMs / 1000);
    if (s.vigorWinded && s.vigor >= MOVE.WINDED_RESUME) s.vigorWinded = false;
}

export const canSprint = s => !s.vigorWinded && s.vigor > 0;

export function spendHop(s) {
    if (s.vigor < MOVE.HOP_COST) return false;
    s.vigor -= MOVE.HOP_COST;
    s._vigorIdleMs = 0;
    if (s.vigor <= 0) s.vigorWinded = true;
    return true;
}

export function moveSpeed(base, fatigue, statusMult, sprinting) {
    return Math.floor(base * (1 - fatigue * 0.75) * statusMult * (sprinting ? MOVE.SPRINT_MULT : 1));
}

// Longest hop (in 16 px steps, up to maxDist) whose landing is open and whose
// path crosses only open or hoppable ground. 0 = hop in place.
// blockedAt(x, y) → 'wall' | 'hop' | null for the player's feet at (x, y).
export function hopLanding(from, dir, blockedAt, maxDist = MOVE.HOP_MAX_DIST) {
    const len = Math.hypot(dir?.x ?? 0, dir?.y ?? 0);
    if (!len) return 0;
    const ux = dir.x / len, uy = dir.y / len;
    for (let d = maxDist; d >= 16; d -= 16) {
        if (blockedAt(from.x + ux * d, from.y + uy * d) !== null) continue;
        let clear = true;
        for (let s = 8; s < d; s += 8) {
            if (blockedAt(from.x + ux * s, from.y + uy * s) === 'wall') { clear = false; break; }
        }
        if (clear) return d;
    }
    return 0;
}

// Low things a hop clears. Tall fences (iron), big stumps and barrels stay walls.
export const HOPPABLE_NAME = /^(fence_wood_|wood_post_fence|log_|stump_small|rock_small|small_stone_nub|crate_|market_crate_)/;

export function isHoppableDecoration(placement, entry, hopCells = null) {
    if (typeof placement.hoppable === 'boolean') return placement.hoppable;
    if (entry?.hoppable === true) return true;
    if (hopCells?.has(`${placement.x},${placement.y}`)) return true;
    return HOPPABLE_NAME.test(placement.name ?? '');
}
```

```js
    // blockedAt(x, y) → 'wall' | 'hop' | null for this player's feet at (x, y) (GameScene._hopBlockedAt).
    tryHop(blockedAt) {
        if (!this.active || this.isHopping || this.isAttacking) return false;
        if (statusManager.isStunned(this) || this.stats.manaCollapsed) return false;

        }

        const dir  = this._moveDir ?? facingDir;
        const len  = Math.hypot(dir.x, dir.y) || 1;
        const dist = hopLanding({ x: this.x, y: this.y }, dir, blockedAt);
        const v    = dist / (MOVE.HOP_MS / 1000);
        this._hopVel      = { x: dir.x / len * v, y: dir.y / len * v };

        this._hopIframeMs = MOVE.HOP_IFRAME_MS;
        this.isHopping    = true;

    }

        this._hopT += delta;
        const t = Math.min(1, this._hopT / MOVE.HOP_MS);
```
