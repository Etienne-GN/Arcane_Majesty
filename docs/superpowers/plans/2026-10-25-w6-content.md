# W6 Content: Thaloria and the Thalorian Wilds — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Chapter 3's area at full scale:
- **Thaloria** becomes a walled city of 128×112 tiles:
  - five districts;
  - 17 rooms behind its doors;
  - 40 people on schedules.
- **The East Road** becomes **the Thalorian Wilds**, 192×160 tiles of forest:
  - dense stands to get lost in;
  - side paths, a birch copse, a ruin, a lake with a stream to hop, and a cave;
  - nine landmarks.

Chapter 3's quests keep working on the new layout, and old saves keep loading.

**Architecture:** Both maps become W2 regions, written by their Python generators through `region_writer.py` into `src/data/maps/regions/`. Each map's layout lives in a small Python module that its generators share:
- `thaloria_layout.py`: streets, buildings and their rooms, and the people's spots;
- `east_road_layout.py`: road, paths, clearings, water and key spots.

The interior generator reads them for door positions. The city generator writes `src/data/townsfolk/thaloria_places.js` for W4, and the hand-written `thaloria.js` lists the 40 residents against those places. A map's `layoutVersion` is stamped on saved positions, so an old save never resumes at a spot that is now a wall.

**Tech Stack:** Python 3 generators (`sheetmap.py`, `region_writer.py`, `gen_interiors.py`), Phaser 3.90, ES modules, Node `assert` tests, headless Chrome via `../tool_suite/lpc_forge/tools/console.mjs`.

**Spec:** `docs/superpowers/specs/2026-10-17-world-scale-design.md` (section W6, plus Goals 3–6)

```js
// W6: a saved spot remembers the layout of the map it was saved on (no field = 1).
// When a map is rebuilt (its layoutVersion goes up), an old spot is meaningless —
// it may now be a wall — so Continue and respawn use that map's start instead.
export const stampLayout = (spot, layout = 1) => ((layout ?? 1) === 1 ? spot : { ...spot, layout });
const sameLayout = (spot, layoutOf) => (spot.layout ?? 1) === (layoutOf(spot.mapId) ?? 1);

// Continue: the saved location, or undefined fields so GameScene uses its default map.
export function continueTarget(stats, mapExists = () => true, layoutOf = () => 1) {
    const loc = stats.location;
    if (loc?.mapId && mapExists(loc.mapId)) {
        return sameLayout(loc, layoutOf)
            ? { mapId: loc.mapId, spawnX: loc.x, spawnY: loc.y }
            : { mapId: loc.mapId, spawnX: undefined, spawnY: undefined };
    }
    return { ...NONE };
}

// After death: the respawn point, else the start of the map you died on.
export function respawnTarget(stats, deathMapId, mapExists = () => true, layoutOf = () => 1) {
    const p = stats.respawnPoint;
    if (p?.mapId && mapExists(p.mapId)) {
        if (sameLayout(p, layoutOf)) return { mapId: p.mapId, spawnX: p.x, spawnY: p.y, label: p.label ?? null };
        return { mapId: p.mapId, spawnX: undefined, spawnY: undefined, label: null };
    }
    return { mapId: deathMapId, spawnX: undefined, spawnY: undefined, label: null };
}

export function setRespawnPoint(stats, mapId, x, y, label = null, layout = 1) {
    stats.respawnPoint = stampLayout({ mapId, x: Math.round(x), y: Math.round(y), label }, layout);
}
```

export function resolveDeath(stats, deathMapId, mapExists = () => true, { online = false, layoutOf = () => 1 } = {}) {
    if (online) return { glintLost: 0, target: { mapId: undefined, spawnX: undefined, spawnY: undefined, label: null } };
    const { glintLost } = applyDeathPenalty(stats);
    const target = respawnTarget(stats, deathMapId, mapExists, layoutOf);
    stats.location = stampLayout({ mapId: target.mapId, x: target.spawnX, y: target.spawnY }, layoutOf(target.mapId));
    return { glintLost, target };
}

"""

tiles = [[0] * W for _ in range(H)]

def inside(x, y):
    return 0 <= x < W and 0 <= y < H


def path(points, width):
    """Straight legs through the points: horizontal on the first point's row, then vertical."""
    for (x0, y0), (x1, y1) in zip(points, points[1:]):
        for x in range(min(x0, x1), max(x0, x1) + 1):
            for d in range(width):
                if inside(x, y0 + d):
                    tiles[y0 + d][x] = 2
        for y in range(min(y0, y1), max(y0, y1) + 1):
            for d in range(width):

q = deque()
for y in range(H):

            dist[y][x] = 0
            q.append((x, y))
while q:
    x, y = q.popleft()
    if dist[y][x] >= 12:
        continue
    for nx, ny in ((x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)):
        if inside(nx, ny) and dist[ny][nx] > dist[y][x] + 1:
            dist[ny][nx] = dist[y][x] + 1
            q.append((nx, ny))


def noise(x, y):
    return (math.sin(x * 0.07) + math.sin(y * 0.09) + math.sin((x + y) * 0.04) + math.sin((x - y) * 0.06)) / 4


for y in range(H):
    for x in range(W):
        if tiles[y][x] == 2 or (x, y) in keep_open or dist[y][x] <= 2:
            continue
        thinner = 0.2 if dist[y][x] <= 5 else 0.0
        if noise(x, y) + rng.uniform(-0.3, 0.3) > L.TREE_THRESHOLD + thinner:
            tiles[y][x] = 1
for x in range(W):

for y in range(H):
    tiles[y][0] = tiles[y][W - 1] = 1
for y in (L.WEST_Y, L.WEST_Y + 1):

for y in (L.EAST_Y, L.EAST_Y + 1):
    tiles[y][W - 1] = 2
dense = [(x, y) for y in range(H) for x in range(W) if noise(x, y) > L.DENSE_NOISE and dist[y][x] > 5]

# ------------------------------------------------------------------ water pieces (shore from the neighbours)
WATER_NAMES = set(sm.catalogue(WATER)[1])


def is_water(x, y):
    if not inside(x, y):                            # the stream runs on past the east edge
        return (min(max(x, 0), W - 1), min(max(y, 0), H - 1)) in water
    return (x, y) in water


def water_piece(x, y):
    n, s, e, w = is_water(x, y - 1), is_water(x, y + 1), is_water(x + 1, y), is_water(x - 1, y)
    missing = ''.join(d for d, v in (('n', n), ('s', s), ('e', e), ('w', w)) if not v)
