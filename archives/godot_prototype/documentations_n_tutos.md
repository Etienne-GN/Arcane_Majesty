# Godot Learning Resources

A curated list of tutorials and documentation to guide you through the development of Arcane Majesty, based on our project roadmap.

---

## Phase 1: Foundations

This section covers the initial setup and fundamental concepts of Godot.

### Your First 2D Game (Official Tutorial)

This is the best starting point for learning the Godot editor, scenes, and scripting.

*   **Official Godot Documentation:** [Your first 2D game (Dodge the Creeps!)](https://docs.godotengine.org/en/stable/getting_started/first_2d_game/index.html)

### TileSet & TileMap

Learn how to create the world of your game. This is a crucial skill for this project.

*   **Official Documentation:** [Using TileSets](https://docs.godotengine.org/en/stable/tutorials/2d/using_tilesets.html)
*   **Video Tutorial (GDQuest):** [Godot 4 Tilemap Tutorial](https://www.youtube.com/watch?v=Dga_n_a22aU)
*   **Video Tutorial (HeartBeast):** [Godot 4 2D Tilemap Basics](https://www.youtube.com/watch?v=MCC-B-iS2M4)
